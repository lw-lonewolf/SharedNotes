Used for achieving consistency, conciseness, completeness and correctness 

It is a software specification and production method based on precise mathematical syntax and semantics normally used in sensitive settings. e.g. Safety Critical Systems, High Financial Risk, verification of COTS

> COTS stands for Commercial Off-The-Shelf software or systems. Verification of COTS means thoroughly testing and validating pre-made, commercially available software components before using them in your own systems, especially when those systems are critical or high-risk.
  why COTS verification is so important. Imagine you're building an aircraft navigation system, and instead of creating every component from scratch, you decide to use a commercially available GPS module. While this saves time and money, you can't simply trust that it will work perfectly in your specific use case – lives depend on it.

##### Methods: 
1) Model-Based (explicit definition of state and operations)
	* Z, B, Vienna
2) Algebraic (implicit definition of operations without defining state)
	* Larch, PLUS, OBJ
3) Logic Based (describe system logic using predicate logic)
	* Temporal, Interval
4) Net-Based (implicit concurrent models dataflow through a network)
	* Petri-Nets
