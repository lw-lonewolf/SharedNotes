This is how you convert raw data into a frequency distribution:
#### Steps for Creating a Frequency Distribution 
* Calculate Range = $X_{m}$ - $X_{o}$
* Find the number of Classes = $k$ = $1.33\log{n}$
* Find the class interval $\frac{R}{k}$

>[!caution] If $k$ or class interval is a decimal value convert it to integer by rounding it up to the next whole number. (take ceiling)

*Starting Point:* Use the minimum value as the starting point for classes.

A sample frequency distribution: 

| Classes | Frequency |
| ------- | --------- |
| 5-10    | 2         |
| 10-15   | 2         |
| 15-20   | 5         |
| 20-25   | 5         |
| 25-30   | 3         |
| 30-35   | 3         |

If the class interval is very small than we do not create class intervals and instead use a bar chart or pie chart for graphical representation of the data instead of histograms.
