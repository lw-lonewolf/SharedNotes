## **1. Measurement Scales**

Measurement scales define the level of measurement of variables.

### **Types of Measurement Scales**

1. **Nominal Scale** (Qualitative, No Order)
    
    - Used for categorization only.
    - Example: Gender (Male, Female), Colors (Red, Blue).
2. **Ordinal Scale** (Qualitative, Ordered)
    
    - Categories have a meaningful order, but differences between them are not measurable.
    - Example: Education Level (Primary, Secondary, Tertiary).
3. **Interval Scale** (Quantitative, No True Zero)
    
    - Differences are measurable, but there is no absolute zero.
    - Example: Temperature in Celsius or Fahrenheit (0°C does not mean no temperature).
4. **Ratio Scale** (Quantitative, True Zero)
    
    - Has all properties of an interval scale but with a meaningful zero point.
    - Example: Height, Weight, Age, Income.

## **2. Summarization of Qualitative and Quantitative Data**

- **Qualitative Data (Categorical):** Represented using frequency tables, pie charts, and bar charts.
- **Quantitative Data (Numerical):** Organized using frequency distributions, histograms, and numerical summaries (mean, median, mode).

### **Graphical Representation**

#### **1. Bar Chart**

- Used for **categorical (qualitative) data**.
- Bars are separated.
- Example: Number of students preferring different sports.

#### **2. Pie Chart**

- Used for **categorical (qualitative) data** to show proportions.
- Example: Market share of different smartphone brands.

## **3. Measures of Central Tendency (Ungrouped Data)**

Measures of central tendency describe the center of a dataset.

1. **Mean (Arithmetic Average)**
    
    - Formula: $$\text{Mean} = \frac{\sum X}{n}$$
    - Example: If marks are **50, 60, 70**, then: $$\text{Mean} = \frac{50 + 60 + 70}{3} = 60$$
2. **Median (Middle Value)**
    
    - If **n is odd**, median = middle value.
    - If **n is even**, median = average of two middle values.
3. **Mode (Most Frequent Value)**
    
    - The value that appears most often.
    - Example: **5, 7, 7, 8, 10** → Mode = **7**.
4. **Trimmed Mean**
    
    - Removes a percentage of highest and lowest values.
    - **Trim %**: Percentage of values removed from both ends.
    - **Total Trim**: The exact number of values removed.
5. **Quartiles & Percentiles**
    
    - **Quartiles**: Divide data into **four equal parts** (Q1, Q2, Q3).
    - **Percentiles**: Divide data into **100 equal parts**.

## **4. Graphical Representations**

### **Dot Plot**

- Shows frequency of individual data points along a number line.

### **Five-Point Summary**

Consists of:

1. **Minimum Value**
2. **Q1 (First Quartile, 25%)**
3. **Median (Q2, 50%)**
4. **Q3 (Third Quartile, 75%)**
5. **Maximum Value**

### **Box Plot (Box-and-Whisker Plot)**

- Displays five-point summary and outliers.
- Outliers are extreme values beyond **1.5 × IQR**.

### **Outlier Detection**

- **Box Plot Rule**: Outliers are **outside 1.5 × IQR**.
- **Z-score Rule**: If **|Z| > 3**, the data point is an outlier.

### **Skewness**

- **Right-skewed (Positive Skew)**: Mean > Median > Mode.
- **Left-skewed (Negative Skew)**: Mean < Median < Mode.
- **Symmetric (No Skewness)**: Mean = Median = Mode.

#### **Pearson’s Coefficient of Skewness**

- Formula: $$Sk = \frac{3(\text{Mean} - \text{Median})}{\text{Standard Deviation}}$$
- If **Sk > 0** → Right skewed.
- If **Sk < 0** → Left skewed.

## **5. Measures of Dispersion (Ungrouped Data)**

Measures how spread out the data is.

### **1. Range**

$\text{Range} = \text{Max} - \text{Min}$

Example: If **max = 100** and **min = 40**, then **Range = 100 - 40 = 60**.

### **2. Variance**

$$\sigma^2 =  \frac{\sum F(X-\bar{X})}{\sum F}$$

Measures average squared deviation from the mean.

### **3. Standard Deviation**

$\sigma = \sqrt{\text{Variance}}$

Measures how much data deviates from the mean.

### **4. Interquartile Range (IQR)**

$IQR = Q3 - Q1$

Measures spread between **first and third quartile**.

### **5. Coefficient of Variation (CV)**

$$ \frac{\sigma}{\bar{x}} \times 100\%$$

Measures relative variability in percentage form.

## **6. Cross Tabulation (Contingency Table)**

A method for analyzing relationships between **two categorical variables**.

Example:

|Gender|Likes Sports|Doesn't Like Sports|
|---|---|---|
|Male|40|10|
|Female|30|20|

It helps in finding **relationships and dependencies** between variables.
