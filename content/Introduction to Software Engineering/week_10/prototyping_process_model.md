# PROTOTYPING MODEL
(1) -> Communication -> Quick Plan -> Modeling/Quick Design -> Constr. of Prototype -> Deployment(Delivery & Feedback) -> (1) 

## Advantages: 
-> Improved Communication 
-> Improved User Involvement
-> Clarification of Partially Known Requirements 
-> Less Maintenance Costs 
-> Production of Expected Results 

## Disadvantages: 
-> Lack of Project Standards (possible) 
-> Lack of Control (project can spiral) 
-> Additional expense (quick planning/modeling can incur this.

## WHEN TO USE 
-> Fuzzy/Unclear requirements, assists in better understanding this. 
-> When requirements may change frequently 
-> Need to quickly validate and refine system req. 
-> When Stakeholder require early prototypes for feedback and validation
