# Incremental Model: 
P(A) -> P(B(A)) -> P(C(B(A)))

# Advantages: 
-> Testing at each phase, less chance of failure. 
-> Lowers delivery cost 
-> Flexible and can accomodate changes in requirements with incurring a smaller cost 
-> Easier to recognize errors 

# Drawbacks 
-> Requires proper analysis and design 
-> Total Cost is more than a traditional waterfall method 
-> Modules need to be clearly defined 
-> Need a complete understanding of the system's working before it is broken down and built incrementally. 

# When to Use:
-> Requirements are understood clearly 
-> There is a demand for the early release of the project
-> This type of approach is followed on companies whose softwares have low defects risk in their products. ALso used in developing web apps. 
-> Project has lengthy dev schedules. 
> NOT FOR PROJECTS WITH HIGHLY STABLE REQUIREMENTS
