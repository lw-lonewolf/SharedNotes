# Evolutionary Process Model (Spiral Model)

(1) -> Communication -> Planning -> Modeling -> Construction -> Deployment -> (2)
(2) -> Communication -> Planning -> Modeling -> Construction -> Deployment -> (3)
... so on 

# Advantages 
-> High amounts of risk analysis present. 
-> Good for Large Projects. 
-> Strong Approval and Documentation Control 
-> Additional Functionality can be added later on 
-> Software is produced early in the cycle

# Disadvantages: 

-> Can be a costly model to use 
-> Risk analysis requires highly specific expertise 
-> Projects success is highly dependent on the risk analysis phase 
-> Does not work well for small projects

## When To Use: 
-> Risk Evaluation is important
-> Medium to high-risk projects
-> Users are unsure as to what they want 
-> Complex Requirements 
-> New Product Line 
-> Significant changes are expected (research/exploration)
