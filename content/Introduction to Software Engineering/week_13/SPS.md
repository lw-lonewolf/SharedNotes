# SOFTWARE PROJECT SCHEDULING

Distributes estimated effort across planned project.
First of all the initial schedule is macroscopic and focuses on the major framework activites of a project and the shit to which it is applied. 
As the project continues, the schedule becomes more detailed and each task is given specific quota etc.

# CRITICAL PATH

if the tasks on the critical path are incomplete, the completion date is directly effected. 
Other task can be completed without worry about them effecting the end date.
