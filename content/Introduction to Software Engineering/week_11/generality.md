# GENERALITY 

 Every time there is a problem, try to solve it using a easier/more general method than just going all in. the problem may not 
 even be as difficult as it seems. This way the generalized problem has more potential to be reused afterwards. By going towards 
 a general solution you may just end up developing a module that is used at more than one point in the code instead of rewriting 
 it each and every time.
