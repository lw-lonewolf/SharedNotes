# ANTICIPATION OF CHANGE

Software is a product that keeps changing/evolving over time. i.e. it is not a static fucking component. Anticipation of change 
is what sets software aside from other industrial products because the developers/creators must "anticipate" that there will be 
change in this product, and hence use shit like: 

-> maintainability
-> modifiability 
-> reusability 
-> evolvability 
-> modularity

requires appropriate tools to manage various versions and revisions of the software.
