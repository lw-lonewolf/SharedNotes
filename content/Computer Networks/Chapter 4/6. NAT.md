All devices share one (public) IPv4 address. ***NAT WORKS ON LAYER 3 (NETWORK) ON THE OTHER HAND***. ***PAT WORKS ON LAYER 4 (TCP/UDP)***

## Difference in NAT and PAT 
NAT IS 1:1. One public ip addr for one private ip addr
PAT is 1:many. One public ip addr for many private ip addr 

## How does it work? 
* NAT replaces every *outgoing datagram*'s source ip addr, port# with NAT ip addr, new port.
* remote/clients will respond using NAT ip addr, new port.
* **IN NAT TRANSLATION TABLE:** every (source ip addr, port) -> mapped to -> (NAT ip addr, new port)
* incoming datagram: replace (NAT IP addr, new port) -> (source ip adr, port)
