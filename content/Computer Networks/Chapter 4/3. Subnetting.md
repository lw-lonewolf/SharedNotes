## Subnetting Example 
assume someone sends data to 200.10.2.45   (a device in IT department)

* External Router knows `200.10.0.0/16` -> company gateway. So it sends it there.
* Company Gateway (edge router) now knows `200.10.2.0/24` so it forwards it to IT subnet.
* Now internal router in that subnet will send it to destination.

## Subnet Masks
A subnet mask is a **32-bit pattern** that indicates how many bytes are for network id and how many are for the host id. e.g. `192.168.8.1` has the subnet mask **255.255.255.0** or `11111111.11111111.11111111.00000000` i.e. the first 24 bits represent the network, while the next 8 bits are for the host. 
### Masking (Bitwise AND) 
Process of extracting network/subnet ID using AND($\And$) operation with the subnet mask.

### Default Masks (CLASSFUL)
A -> `255.0.0.0`
B -> `255.255.0.0`
C -> `255.255.255.0`

### Block Size
Range of ips for each subnet. Better understanable from below example. 

>[!example] Using block size to determine subnet 
>`128.125.0.0/19` for subnets 
>Mask would be `255.255.224.0`
>From the last network octet `224` we get block size = $256-224 = 32$
>
>Subnet ranges are then:
>* 0 0-31
>* 32 32-63
>* 64 64-95
>* 96 96-127
>and so on until we reach 224
>
>No if we had an ip `128.125.70.5`, 3rd octet = 70 falls within 64-95, so subnet is `128.125.64.0`.
>
>All of this can be achieved using AND as well. `01000110(70) & 01000000(224) = 01000000(64)`
