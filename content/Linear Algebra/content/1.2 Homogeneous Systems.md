### General Solution: 
If a linear system has infinitely many solution then a parametric solutions then a parametric equations from which all solutions can be obtained by assigning numerical values to the parameters is called a general solution of the system.

### Variable Theorem For Homogeneous System
If a homogeneous linear system has n unknowns and if the reduced row echelon form of it's augmented matrix has `r` non zero rows then the system has `n-r` free variables.
