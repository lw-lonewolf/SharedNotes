###### Parallel and Collinear Vectors
Two vectors are said to be parallel if they have either the same direction or opposite direction and this means that one vector is scalar multiple of the other.
![[3.1 Euclidean Vector Space 2024-09-25 10.29.43.excalidraw]]
###### Collinear Vectors
Two vectors are said to be collinear when they are along the same line.

###### Algebraic Properties of Vectors
$\vec{u} + \vec{w} = \vec{w} + \vec{u}$
$(\vec{u}+\vec{v})+\vec{w} = \vec{u} + (\vec{v} + \vec{w})$
$\vec{u} + \vec{0} = \vec{0} + u =u$
$\vec{u} + (-\vec{u}) = \vec{0}$
$k(\vec{u} + \vec{v}) = k\vec{u} + k\vec{v}$
$(k+m)\vec{u} = k \vec{u} + m \vec{u}$
$1\cdot\vec{u} = \vec{u}$
##### Linear Combination
If $w$ is a vector in $R^n$ then w is said to be linear combination of vectors $v_{1}+v_{2}+\dots+v_{n}$ in $R^n$ then it can be expressed as $\vec{w} = k_{1}\vec{v_{1}} + k_{2}\vec{v_{2}}+\dots+k_{n} \vec{v_{n}}$.
