If $S = \{\vec{v_{1}}, \vec{v_{2}}, \dots ,\vec{v_{r}}\}$ is a set, of two or more vectors in a vector space $V$, then $S$ is said to be a linearly Independent set  if no vector can be expressed as a linear combination of others. A set that is not linearly independent is said to be linearly dependent.

A non empty $S = \{\vec{v_{1}}, \vec{v_{2}}, \dots, \vec{v_{r}}\}$ in a vector space $V$ is linearly independent if and only if the coefficients satisfy the equation 
$k_{1}v_{1} + k_{2}v_{2} + \dots + k_{r}v_{r} = 0$
