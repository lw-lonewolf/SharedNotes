A square matrix in which all the entries above the main diagonal are zero is called **lower triangular matrix**. 
$\begin{matrix}a_{11} &a_{12} &a_{13} \\ 0 &a_{22} &a_{23} \\ 0 &0 &a_{33}\end{matrix}$

A square matrix in which all the entries below the main diagonal are zero is called **upper triangular matrix**
$\begin{matrix} a_{11} &0 &0 \\ a_{21} &a_{22} &0 \\ a_{31} &a_{32} &a_{33}\end{matrix}$

###### Theorem: 
A triangular matrix is invertible if and only if the diagonal entries are all nonzero. 

$\begin{matrix} 1 &2 &3 \\ 0 &0 &1 \\ 0 &0 &3\end{matrix}$

(not invertible)

#### Theorem: 
If `A` is an invertible symmetric matrix then `A^-1` is symmetric. 
###### Proof:
Given that `A^t = A` we have to show that $(A^{-1})^{t} = A^{-1}$
(A^-1)t = (At)-1
	   = (A)^-1
	proved.
