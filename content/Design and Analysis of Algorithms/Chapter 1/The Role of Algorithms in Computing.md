### Algorithms
An *algorithm* is any well-defined computational procedure that takes some value, or set of values, as *input* and produces some value, or set of values, as *output* in a finite amount of time. An algorithm is thus a sequence of computational steps that transform the input into output.

An example (a *sorting problem*) would be: 
**Input**: A sequence of $n$ numbers $(a_{1}, a_{2}, a_{3}, \dots, a_{n})$
**Output**: A permutation (*reordering*): $(a_{1}', a_{2}', a_{3}', \dots, a_{n}')$ of the input sequence such that $a_{1}' \leq a_{2}' \leq a_{3}' \leq\dots\leq a_{n}'$

So given the sequence $(31, 41, 59, 26, 41, 58)$, a correct sorting algorithm should return as output the sequence $(26, 31, 41, 41, 58, 59)$
### Instances
In the above example the numerical input sequence is called an *instance* of the sorting problem. In general, an *instance of a problem* consists of the input which satisfies whatever constraints are imposed needed to compute a solution.
### Data Structures 
A *data structure* is a way to store and organize data in order to facilitate access and modifications. Using the appropriate data structure or structures is an important part of algorithm design.
