## Object Oriented Paradigm
Follows: 
-> abstraction
-> encapsulation 
-> inheritance (mechanism for sharing properties from parent to child classes.)
-> polymorphism (allows you to use a common name for a function and then behind the scenes the appropriate function gets called. _If we have a game of chess, a chess has pieces, a single function called move that can move all pieces but according to their own movement principles._)

>[!caution] What is an OOP Language 
>A language to be object oriented it ***must*** provide inheritance.

OOD -> Object Oriented Design.
