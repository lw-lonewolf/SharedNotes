Operating Systems are responsible for the communication between different layers of a computer. i.e. it assists the user in communicating with the system and application programs and then helps these programs to communicate with the underlying computer hardware.
## 1.1.1 The User View 
The user's view of a computer varies according to the interface being used. Most computer users sit in front of a *PC*, consisting of a monitor, keyboard, mouse and system unit. Such a system is designed to monopolize the resources. i.e. there is only one user and the goal is to maximize the work that the user is performing. Here, the OS is designed basically for ease of use and some attention to performance and almost none paid to resource utilization, as various hardware and software resources are not going to be shared.

Other cases involve the user sitting in front of a terminal that is connected to *a mainframe or a minicomputer*. Other users are also accessing the system at the same time. These users share resources and can exchange information. These users share resources and the OS is designed in order to maximize resource utilization i.e. how the available CPU time, memory and I/O are distributed so that each user may not take more than his/her fair share.

Another case is a *workstation* which is connected to a network of other workstations and/or *servers*. These have dedicated resources at their disposal but also involve some shared resources such as networking and servers, that may include file, compute, and print servers.

The latest/last case is that of *mobile computers*, such as smartphones or tablets. These are normally stand alone for single users. They are connected in networks such as cellular networks. These are increasingly replacing laptops/PCs especially for people whose primary concern is checking mail or to browse the internet. The UI normally involves just a *touch screen*. 

Some computers have zero or minimal user view. e.g. embedded computers in home devices and automobiles.

## 1.1.2 System view
From a system view an operating system is a program that is involved with the hardware most intimately. In this view an operating system can be viewed as a *resource allocator*. The operating system acts as a manager for the resources of a computer.

Another view could be that of a *control program*. A *control program* manages the execution of user programs while attempting to prevent errors and improper use of the computer. 

## 1.1.3 Defining Operating Systems 
There is no complete adequate definition of an operating system, they exist because they offer a reasonable way to solve the problem of creating a usable computing system. The main goal of computer systems is to execute user programs and make solving user problems easier. Since it is difficult use bare hardware, application programs are developed. 

The main and followed Definition of an operating system is: 
```
An operating system is the one program which is running at all times on a computer - usually called the kernel. Along with this there are two other types of programs. System programs, which are associated with the operating system but are not necessarily part of the kernel, and application programs, which include all programs not associated with the operation of the system.
```
