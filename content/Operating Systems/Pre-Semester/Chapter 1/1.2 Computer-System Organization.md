## 1.2.1 Computer-System Operation 

For a computer to start running - when it is rebooted or powered on, it needs to have an initial program running. This initial program or *bootstrap program*, tends to be simple. It is normally stored within the computer hardware in ROM or EEPROM. This is known generally be the term firmware. It initializes all aspects of the system, from CPU registers to device controllers to memory controls. The bootstrap program must know how to load the OS and how to start executing the system. To accomplish this, it must located the kernel and load it into the memory. Once it is loaded it can start executed and provide services. Some services are provided outside of the kernel that are loaded into memory at boot time to become *system processes* or *system daemons* which run the entire time the kernel is running

The occurrence of an event is usually signaled by an *interrupt* from either the hardware or the software. Hardware may trigger an interrupt at any time by sending a signal to the CPU, usually by the system bus. Software may trigger an interrupt by executing a special operation called a *system call*.
