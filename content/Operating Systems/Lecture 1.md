
The computer system consists of hardware and software that are combined in order to provide a tool to implement solutions for a specific problem in an efficient manner. 

### Definition of an Operating System 
Two views: 

`The intermediary between the user of a computer and the computer hardware and makes using the system more convenient.`

`The program that allocates and deallocates computer system resources in an efficeint fair and secure manner. i.e. A resource manager`

`A slightly differenct view of an OS is the need to control the I/O devices and programs.`
