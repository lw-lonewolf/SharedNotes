# ER to Relational Mapping Algorithm 

* Map Regular Entities 
* Map Weak entities
* Map Binary 1:1 relationship
* Map Binary 1:N Relation
* Map Binary M:N Relation
* Mapping of Multivalued attributes
* Mapping of N-ary Relationships
If(EER) then continue with: 
* Mapping Specialization/Generalization
* Mapping Union Types (Categories)
# 1-1 With Total participation
Relationship relation: Build a table and add columns for each participating entity’s primary key. Also add the attributes of the relationship. (cross-reference)

# 1-1 Relationship with one total participation
Foreign Key Approach: Add primary key of the entity without total participation in the table of entity with total participation.

# 1-1 with total participation for both 
Merge the two entitles and the relationship into a single relation.
