Memory depends upon three sequential processes 
1) Encoding
2) Storage
3) Retrieval

Attention plays a very important role in memory, unless you pay attention, information is not retained.

*Selective Attention:* This helps filter out unwanted stimuli or events, allowing for coherent thought and functioning in everyday life. This means focusing on a specific range of stimuli.  

*Multitasking and Attention:* People who multitask frequently are often the least capable of handling multiple tasks. 
Multitasking between tasks means you are dividing attention and this means reduced performance overall. Our brain is only capable of handling one attention specific task at a time.

# Types of Memory
#### Sensory Memory 
* Initial Storage of Information
* Brief Storage of Sensory Information 
* Types: Iconic Memory(visual), Echoic Memory(auditory)
* Duration: a fraction of a second to a few seconds 
#### Short Term Memory
* Transformation of sensory memory to meaningful information
* Limited capacity, Holds up to several items or "chunks" of information.
* Duration: Lasts for 15 to 25 seconds
* Rehearsal: Repetition of information aids in transfer to long-term memory
#### Working Memory 
* Contemporary view: Short Term Memory is an active processing system 
* Working memory contains both new and old information
* Contains central executive processor and storage systems: visual, verbal, episodic buffer
* Example: Multi step arithmetic problem solving
#### Long Term Memory 
* Stores information on a relatively permanent basis 
* Almost unlimited storage
* Types: Declarative, Procedural

#### Declarative
* Handles factual information
* recollections of names, words, definitions, events, faces, concepts and ideas 
###### Semantic:
The semantic memory system contains general knowledge that is not tied to the time when the information was learned.
###### Episodic Memory:
The episodic memory system is made up of chronological, or temporally dated, recollections of personal experiences.

#### Imperative 
* Actions, skills, conditioned responses and emotional memories.
Contains information regarding habits, or procedures, such as cycling typing, tying shoes etc. 

# Improving Memory 
#### Chunking 
Breaking information into smaller, more manageable units (grouping digits of phone numbers etc.)
#### Rehearsal
Repeating information over and over until it is engraved into the mind. Testing can enhance retention.
#### Elaborative Rehearsal
Connecting new knowledge to existing knowledge in order to deepen understanding (creating associations with concepts)

#### Mnemonics
Using patterns, phrases or acronyms to remember information

#### Imagery 
Forming mental images to represent information, which aids in memory recall (e.g. visualizing a story for word lists).
