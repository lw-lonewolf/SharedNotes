>[!warning] QUICK TLDR
>**Horizontal = wide but shallow**  
**Vertical = narrow but deep**  
**T = mix of both**  
**Local = focused experiment**

## Horizontal Prototype 
* Covers many features but on surface level 
* Good for exploring UI layout, navigation and flow 
* Not much real functionality
## Vertical Prototype 
* Focuses on one feature or small set of them in full depth
* Good for testing technical feasibility or detailed user interactions 
## T-Prototype 
* Combines horizontal and vertical 
* Most features are shallow, but key features are deeply implemented 
* Balances breadth and depth of implementation 
## Local Prototypes 
* Focuses on only one specific interaction or design problem 
* Used to compare design alternatives before committing
